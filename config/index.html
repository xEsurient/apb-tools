Config merge

Finds the lines your localisation config is missing compared to the game's own files, adds them in the right places (in English, ready to translate) and gives you the merged config back as a zip, with a summary of what was added to which file. Everything runs in your browser: your files are not uploaded anywhere.

1Reference: the game's lines

No reference chosen: only APBDB item names can be checked.

2Your config

Files are paired with the reference by name (e.g. APBGame.GER ↔ APBGame.int).
