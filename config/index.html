Config merge

Finds the lines your localisation config is missing compared to the game's own files, adds them in the right places (in English, ready to translate) and gives you the merged config back as a zip, with a summary of what was added to which file. Everything runs in your browser: your files are not uploaded anywhere.

1Reference: the game's lines

No reference chosen: only APBDB item names can be checked.

2Your config

The removal options are off by default: compare first and check the "Will be removed" list in a file's details. Which copy of a repeated key the game reads is not verified; the first one is kept. Files are paired with the reference by name (e.g. APBGame.GER ↔ APBGame.int).

3Optional: the previous game version

With the INT files of the version your config was made for, the report lists your lines whose English original changed in the update: they may be out of date.
